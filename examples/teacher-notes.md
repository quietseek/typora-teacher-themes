# 影响化学反应速率的因素 · 教师参考

> 独立教师版，含答案与教学评价建议。与学生作业分开保存、分发。

## 一、学生作业答案

**1. B。** 其他条件相同时，升温通常加快反应。催化剂改变反应历程，不改变题设完全反应的化学计量关系；研碎固体增大接触面积，不能解释为增大固体浓度；反应总量与反应速率不是同一概念。

**2.** v(H₂O₂) = (0.80 − 0.60) / 20 = **0.010 mol·L⁻¹·s⁻¹**。以反应物浓度的减少量除以时间，取正值；不能省略时间单位，也不能误写为 mL·s⁻¹。

**3. 比较 A、B 两组；速率比为 1∶2。** 两组温度等控制条件相同，仅初始浓度不同。平均产气体积速率分别为 20.0 / 60 ≈ 0.333 mL·s⁻¹、20.0 / 30 ≈ 0.667 mL·s⁻¹。比较的是各自收集前 20.0 mL O₂ 阶段的平均值，不能据此认定两组整个反应过程的瞬时速率始终成此比例。

**4.** 在题给条件下，温度由 25 ℃ 升至 35 ℃，收集相同体积 O₂ 的时间由 60 s 缩短至 40 s，说明该阶段平均产气速率增大。**不能由时间数据推出 C 组最终 O₂ 更多**；总量还与初始反应物的量及反应程度有关。若 A、C 均完全分解且无副反应，两组初始 H₂O₂ 的量相同，理论 O₂ 总量相同。

**5. 方案示例：**

| 项目 | 参考要点 |
| --- | --- |
| 自变量与对照 | 一组加入 MnO₂，另一组不加 MnO₂。 |
| 控制条件 | H₂O₂ 初始浓度、溶液体积、反应温度、装置与计时标准相同。 |
| 观测指标 | 同温同压下，比较相同时间内的产气体积；或比较收集相同体积所需时间。 |
| 干扰与改进 | 例如漏气使测得体积偏小，需检查装置气密性；温度变化干扰比较，需控制反应与气体测量条件。 |

两组完全反应的理论 O₂ 总量相同。由 **2H₂O₂ → 2H₂O + O₂↑**，有 n(O₂) = ½n₀(H₂O₂)。加入 MnO₂ 的组在箭头处注明催化条件；未加入的一组分解也能发生，但通常较慢。不能因短时间内未见明显现象就断言没有反应。

## 二、讲义自检参考

理论 O₂ 总量相同，由初始 H₂O₂ 的物质的量决定。达到同一反应进度所需时间受温度、浓度、催化剂等条件影响。催化剂参与反应过程，其质量和化学性质在反应前后不变，不应表述为“完全不参与反应”。

## 三、评价建议

| 维度 | 达成表现 | 需要跟进的表现 |
| --- | --- | --- |
| 符号与定量 | 方程式配平，计算式、结果、单位完整。 | 混淆浓度速率与气体体积速率。 |
| 控制变量 | 选择 A、B 或 A、C，对应不同研究问题。 | 用 B、C 同时变化的条件推断单一因素。 |
| 证据推理 | 明确比较时间段、测量条件与结论范围。 | 将“更快”直接等同于“最终更多”。 |
