# 从反应条件到数据证据

<div class="qm-meta"><span>主题：化学反应速率</span><span>班级：________</span><span>姓名：________</span></div>

> **学习目标**　会计算平均速率，会选择对照组，会区分反应快慢与生成物总量。

## 一、平均反应速率怎么表示

用反应物 A 表示：**v(A) = [c₀(A) − cₜ(A)] / Δt**，取正值；常用单位为 mol·L⁻¹·s⁻¹。它描述指定时间段的平均快慢。

**例题**：恒容溶液中，20 s 内 H₂O₂ 的浓度由 0.80 mol·L⁻¹ 降到 0.60 mol·L⁻¹，则 v(H₂O₂) = (0.80 − 0.60) / 20 = **0.010 mol·L⁻¹·s⁻¹**。

## 二、哪些条件会影响反应速率

| 条件变化 | 常见影响与适用说明 |
| --- | --- |
| 增大反应物浓度 | 其他条件相同时，通常使反应速率增大。 |
| 升高温度 | 其他条件相同时，通常使反应速率增大。 |
| 加入合适的催化剂 | 可加快反应；催化剂的质量和化学性质在反应前后不变。 |
| 增大固体接触面积 | 对有固体参与的反应，研碎通常有利于加快反应；不是增大固体浓度。 |

## 三、怎样用产气数据比较

研究反应：**2H₂O₂ → 2H₂O + O₂↑（催化剂：MnO₂）**。

可比较相同时间内收集的 O₂ 体积，或收集相同体积 O₂ 所需的时间。须保证气体的测量温度、压强一致，并控制漏气等干扰。

> **易错提醒**　ΔV(O₂) / Δt 的单位可为 mL·s⁻¹，它是平均产气体积速率，不能直接写成 mol·L⁻¹·s⁻¹。短时产气较多，也不能直接推断最终产量较大。

## 四、当堂自检

相同量的 H₂O₂ 在有、无 MnO₂ 两种条件下均完全分解且无副反应。理论 O₂ 总量是否相同？哪些条件影响达到终点所需的时间？
