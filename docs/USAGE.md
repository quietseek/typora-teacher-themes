# 教师工作纸 · 多配色主题

适合教案设计、课堂讲义与作业排版的 Typora 主题。版本：1.1。新增五种配色，各有备课、讲义、作业三种版式，共 15 个新主题；原青墨三个主题也已修正打印边框。每个 CSS 文件均可独立使用，无需联网或安装额外字体。

## 立即使用

1. 打开 Typora 的「偏好设置 → 外观 → 打开主题文件夹」，将仓库 themes 目录中的所需 CSS 复制进去。
2. 保存正在编辑的文档后，重新启动 Typora，在「主题」菜单选择「雾蓝备课」「葡萄紫讲义」「石墨作业」等组合。
3. 打开 templates 目录中的 Markdown 文件，另存为自己的教案、讲义或作业，再替换方括号内容。
4. examples 目录内是高中化学“影响化学反应速率的因素”的教案、讲义、学生作业与独立教师参考。根目录 index.html 可离线打开，切换三个版本预览；预览页本身不是 Markdown 编辑器。

在其他电脑安装：Typora → 偏好设置 → 外观 → 打开主题文件夹，将 themes 文件夹内喜欢的 .css 文件复制进去，然后重启 Typora。不要只复制外层文件夹。

## 三个版本

| 主题 | 适合用途 | 区别 |
| --- | --- | --- |
| 备课 | 教学设计、过程表格、备课笔记 | 无衬线正文，间距舒展。 |
| 讲义 | 知识梳理、例题、学习材料 | 宋体正文，阅读节奏适中。 |
| 作业 | 学生练习、答题纸、订正 | 间距较紧，打印结构清晰。 |

所有主题的打印样式均使用黑白配色、宋体正文和黑体标题。系统缺少字体时会回退到可用字体，可能改变行数。macOS 使用宋体与苹方等系统字体。

## 常用写法

普通 Markdown 的标题、列表、引用、表格、加粗等可以直接使用。下面的 HTML 是可选组件；可在 Typora 源代码模式中粘贴，前后各空一行。HTML 容器内部请用 HTML，不要混写未经处理的 Markdown。空白答题区用于纸上书写，不是浏览器输入框。

信息栏：

```html
<div class="qm-meta"><span>班级：________</span><span>姓名：________</span><span>日期：________</span></div>
```

三条答题横线（增减内部 div 即可增减行数）：

```html
<div class="qm-lines"><div></div><div></div><div></div></div>
```

行内填空请使用下面的写法，避免连续下划线被 Markdown 当作强调语法：

```html
答案是<span class="qm-blank">　　</span>。
```

答题框（small 为 18mm，默认 30mm，large 为 48mm）：

```html
<div class="qm-answer large"></div>
```

自定义答题框高度：

```html
<div class="qm-answer" style="--qm-answer-height: 60mm"></div>
```

手动分页（屏幕显示虚线，打印时另起一页）：

```html
<div class="qm-page-break"></div>
```

需要短题与答题框尽量保持在一页，可将它们包在 qm-question 容器内。长于一页的内容仍会被浏览器拆分，不要把整份作业包在同一个容器中。

```html
<div class="qm-question">
  <p><strong>1.</strong> 请说明你的思路。</p>
  <div class="qm-answer"></div>
</div>
```

## 打印与 PDF

推荐 A4 纵向；CSS 默认上、左、右边距 17mm，下边距 18mm。导出或打印对话框的设置可能覆盖 CSS，请以最终预览为准。若出现重复页边距、额外空白页，请先统一纸型与边距，并关闭浏览器附加的日期、网址页眉页脚。

v1.1 为打印表格预留了 2px 的右侧余量，避免满宽表格的右边框被打印区域裁切。边框修正已经应用于全部 18 个主题。

示例作业包含一个手动分页标记，按默认样式为两页。增加题目或改变字体后，应重新检查分页。表格允许跨页，表头尝试重复；单行过高或整张图片超过一页时，需要手动拆分或缩小。

主题不会自动识别题目语义、生成题号、隐藏答案或计算分数。教师参考答案存放在单独文件中，给学生分发时仅选择学生版。Typora 数学公式、任务列表等仍由 Typora 自身渲染；请在实际文档中检查复杂公式和超宽表格。

## 调整字号与颜色

用文本编辑器打开相应 CSS，在文件顶部修改 --qm-accent（强调色）、--qm-size（屏幕正文字号）、--qm-leading（屏幕行距）、--qm-print-size（打印字号）。每个主题在通用变量后有一段版本专用 :root 设置；若同名变量在那里出现，应修改后出现的值。

## 验证范围

浏览器预览与打印检查使用相同 CSS 和示例 Markdown 转换后的 HTML。它覆盖标题、中文段落、表格、引用、答题横线与分页；不等同于所有 Typora 版本的原生编辑器实测。若某处样式与预览不同，请先检查是否有自定义 base.user.css、主题同名 .user.css 或导出设置影响。

## 示例说明与许可

示例统一为高中化学“影响化学反应速率的因素”，以过氧化氢分解为情境，涵盖平均速率计算、浓度与温度的控制变量分析、催化剂与反应总量的辨析。假定已学物质的量浓度与反应速率定义，按必修层级组织，未对齐指定教材版次、年级进度或考试要求。题目和数据均为自编教学示例，不是实验测量记录或实际操作参数；教师答案单独保存。
